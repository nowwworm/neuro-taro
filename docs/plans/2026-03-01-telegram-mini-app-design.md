# Telegram Mini App Design: Neuro-Tarot

## Overview
Transforming the existing Neuro-Tarot web application into a fully integrated Telegram Mini App with a Freemium monetization model using Telegram Stars.

## Core Features

### 1. Pseudo-AI Interpretation Engine
- To eliminate third-party API costs, the tarot readings will be generated by the backend using a template engine.
- A library of mystical, pre-written text blocks for each card in specific positions (Past, Present, Advice, etc.) will be dynamically concatenated to form a cohesive, unique reading.
- The text will weave the user's name directly into the reading for maximum immersion.

### 2. Telegram Integration & Personalization
- The frontend will load `https://telegram.org/js/telegram-web-app.js` to communicate with the Telegram client.
- Using `Telegram.WebApp.initDataUnsafe.user`, the app will fetch the user's `first_name` and `photo_url`.
- The AI will address the user by name, and the user's Telegram avatar will be proudly displayed on their personal Statistics page.

### 3. Monetization (Telegram Stars)
- **The "Energy" Model**: Users receive **1 free reading per day**.
- If a user runs out of energy, the "Make Spread" button transforms into an offer to refill energy using Telegram Stars (e.g., 50 Stars for 3 readings).
- Payment flow uses the Telegram Bot API (`sendInvoice`) and the Mini App frontend (`Telegram.WebApp.openInvoice`).
- Successful payments trigger a webhook on our Node.js server, automatically crediting the user's energy balance.

## Architecture changes

### Database Schema (PostgreSQL)
- **New Table `users`**:
  - `telegram_id` (Primary Key)
  - `first_name`
  - `avatar_url`
  - `energy` (Integer, default 1)
  - `last_free_refill` (Timestamp)
- **Updated Table `readings`**:
  - Add `user_id` (Foreign Key referencing `users.telegram_id`)

### Backend (`server.js`)
- Add a middleware to validate Telegram `initData` hash.
- Add an endpoint `/api/user` to fetch/create user profile and check energy balance.
- Add `/api/buy-energy` to generate a Telegram Stars invoice link.
- Add a webhook `POST /bot-webhook` to listen for successful Star payments.

## Error Handling & Testing
- If a user opens the web platform outside of Telegram, show a "Please open in Telegram" banner, or provide a fallback demo mode.
- Local testing will be facilitated using `ngrok` to expose `localhost:3000` to the Telegram Bot webhook system.
